# Code of Conduct

This project follows the [Contributor Covenant, version
2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be decent to each other. Harassment, personal attacks, and
discriminatory language are not welcome here.

## Scope

Issues, pull requests, discussions and any other space where someone is
representing this project.

## Reporting

Report unacceptable behaviour privately to the maintainer, **@cyberElar**, through
GitHub. Reports are read promptly and handled confidentially. Maintainers may
remove comments, close threads, or block accounts that break these rules.
