# 提鹅鹏 · 单车环岛

> 一只鹈鹕骑着一辆复古单车，环游一座程序化生成的电影感小岛。
>
> **全部内容都是代码生成的**：地形、建筑、树木、动物、贴图、音乐与音效均在运行时
> 由代码合成 —— 没有任何图片/音频/模型文件，不联网，也不需要构建即可开玩。

**▶ 在线试玩：** https://cyberelar.github.io/pelican-island-ride/
（也可以克隆仓库后直接**双击 `index.html`**，支持 `file://` 打开）

## 岛上有什么

**岛屿** —— 6 km × 6 km 地形：11 km 环岛公路（虚线、边线、石子路肩、路灯、护栏、里程牌），
沙滩、悬崖、高山雪顶、带小岛的镜湖、被双拱石桥跨过的河谷、阔叶林、松林、草甸与梯田。

**21 座手工地标** —— 灯塔（夜间旋转光束）、海风村（16 栋房、集市、喷泉、洗衣绳）、
旧鱼港（随浪起伏的渔船）、风车、水车磨坊、巨石阵、树屋、废墟、海蚀拱门与海蚀柱、
湖心亭、热气球（系留/飘浮）、云顶观星台、礼拜堂、起终点门楼、沉船、瀑布、绳索秋千、崖边观景台。

**活着的岛** —— 234 只动物：海鸥、野鸭、苍鹭、兔子、鹿、螃蟹、蝴蝶、蜜蜂、夜间萤火虫、
跃出水面的鱼、远海鲸鱼、海湾海豚；6 套粒子系统：花粉、落叶、炊烟、篝火火星、瀑布水雾、海边浪花。

**玩法** —— 街机风单车物理（坡度重力、按路面变化的摩擦、压弯、腾空、摔车）、
40 根隐藏金色羽毛、28 个地标发现卡（信件框字幕）、8 检查点环岛计时赛（记录最好成绩）、
摄影模式（景深/变焦/网格）、昼夜循环、天气、小地图、速度表、罗盘。

**画面** —— 自定义天空（日月星云与银河）、Gerstner 波浪海面与岸边泡沫、四路混合地形着色、
PMREM 环境光照，以及后期链：泛光、屏幕空间太阳光柱、分离色调、暗角、色差、胶片颗粒、
SMAA，摄影模式还有景深。

**声音** —— 全合成 WebAudio：风、浪、林鸟、虫鸣、海鸥、港口钟声、随路面变化的胎噪、
链条声、车铃、溅水、摔车，以及会随时间与速度演变的生成式环境音乐。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` / `↑` | 加速 |
| `S` / `↓` | 刹车 |
| `A` `D` / `←` `→` | 转向 |
| `Shift` | 冲刺 |
| `Space` | 急刹 |
| `C` | 切换相机：跟随 → 第一人称 → 电影运镜 |
| `P` | 摄影模式（滚轮变焦、`F` 网格） |
| `M` | 小地图 |
| `B` | 车铃 |
| `R` | 回到最近的公路 |
| `Enter` | 开始环岛计时赛 |
| `T` | 时间：黎明 / 正午 / 黄昏 / 夜晚 / 自动循环 |
| `N` | 静音 · `Esc` 暂停 |

手柄同样支持。地址栏加 `?seed=1234` 换一座岛，`?quality=low|medium|high|ultra` 手动指定画质。

## 技术说明

- **three.js r186.1**（WebGL2），用 esbuild 打包成单个 IIFE，因此可以从 `file://` 直接运行。
- 16 个模块通过一个注册表装配：天空、地形、环境、海洋、植被、道具、地标、动物、粒子、
  天气、相机、操控、骑手、收集物、事件、音频；每个模块都是返回
  `{ group, update(dt, state), setQuality? }` 的工厂函数。
- 484 个几何体、195 张程序化贴图、约 75 个着色器程序；high 画质每帧约
  **1 300–2 000 draw call / 300–470 万三角形**（含阴影与后期）。
- 整岛构建约 4–11 秒（视 CPU），加载页显示进度。

## 开发

```bash
npm install          # three + esbuild + playwright-core（仅开发用）
npm run build        # 生成 dist/game.js（压缩）
npm run build:publish# 同时刷新仓库根目录的可玩副本（game.js、styles.css）
npm test             # 8 个模块测试套件，全部在 Node 中无头运行
npm run serve        # 本地静态服务器 http://localhost:5577/
npm run shots:readme # 重新生成 screenshots/
```

仓库根目录就是可发布的站点：`index.html` + `game.js` + `styles.css`。
`game.js`、`styles.css` 是**有意提交**的构建产物，这样 GitHub Pages 无需 CI 即可直接托管游戏。
